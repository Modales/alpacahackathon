## Project title
APEX — Autonomous Options-Alpha Agent with an Anti-Overfitting Research Pipeline

## Short description (tagline)
An autonomous Alpaca trading agent where nothing trades live unless it survives walk-forward out-of-sample gates — 16 strategies tested, 10 rejected, plus a signal-keyed options wheel (CSPs + covered calls) already running on a fresh $100k paper account.

## Long description
APEX is an autonomous trading agent built on Alpaca's paper environment whose core product is a scientific pipeline, not a single strategy. Every hypothesis is explicit code that must pass pre-registered defenses before trading: three unseen walk-forward windows, an 18-perturbation sensitivity plateau, and hard deployment gates (OOS Sharpe ≥ 0.5, all folds positive, IS→OOS degradation < 50%, maxDD < 20%).

The live system runs three sleeves: (1) a momentum core ranked by our own intraday-flow momentum signal (institutional accumulation shows up intraday; validated OOS at Sharpe 1.20 vs 1.11 for classic momentum); (2) an RSI(2) pullback sleeve on momentum leaders; (3) an options wheel — cash-secured puts on validated dip signals and covered calls on 100+ share positions, with resting 50% profit-take orders. A SPY 200-day regime gate and a −2.5% daily kill switch bound the downside.

Everything is auditable: identical code in backtest / validation / live, an order ledger where every trade carries its signal reason, an official-SDK reconciliation pass each cycle, an official MCP-server verification script, and a self-updating public journal (LIVE.md) plus a single-file demo app (dashboard.html) regenerated after every run. Tech: Alpaca Trading API (hand-rolled REST + official alpaca-py + official alpaca-mcp-server), Market Data API (IEX), OPRA option snapshots with greeks, cron-scheduled autonomous operation.
